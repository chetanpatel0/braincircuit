An installable, offline capable electronic circuit simulator that runs entirely in your browser - on phone, tablet and desktop.

Circuit simulation Works offline Installable PWA Cross platform

What it does

  • Draw circuits with resistors, capacitors, inductors, diodes, transistors, op amps, logic gates, motors, antennas and 100+ more elements
  • Real time transient (time domain) simulation with live oscilloscope graphs
  • DC operating point, AC analysis, frequency response / FFT and signal power charts
  • Custom subcircuits, custom functions, custom logic and SPICE style device models
  • Open, save, import and export circuits as file, text or shareable link
  • Export schematics as PNG / SVG images, print, undo / redo and full keyboard shortcuts

Technologies used

Application typeProgressive Web App (PWA) - installable, offline capable, works on any device
LanguageJava 8 (business logic and UI), JavaScript, HTML5, CSS3
Compiler / frameworkGoogle Web Toolkit (GWT) 2.8.2 - compiles Java to optimized JavaScript
Build toolingGradle 8.7, Java HotSpot JDK 8
RenderingHTML5 Canvas 2D drawing engine, Fontello icon webfont, canvas2svg for SVG export
Simulation engineCustom circuit solver - Modified Nodal Analysis (MNA) with sparse LU matrix decomposition, trapezoidal / backward Euler integration, adaptive time step, DC, AC, transient and FFT analysis
Device modelsSPICE style diodes and LEDs, bipolar transistors, JFET / MOSFET / SCRs, op amps, digital logic families, relays, custom subcircuits
Data & storageWeb Storage (localStorage / sessionStorage), LZ-String compression for shareable circuit URLs, XML circuit format
NetworkingHTTP requests, optional WebSocket link, optional audio input / output, optional Dropbox import
Microcontroller simAVR8js - 8 bit AVR emulation in JavaScript
Install / offlineWeb App Manifest + Service Worker caching (pre-caches the whole app so it opens with no internet)
LanguagesInterface translated into 15 languages (GWT i18n)
Desktop packagingElectron wrapper available for Windows / macOS / Linux

Install on this device

Works on Android, iPhone, iPad, Windows, macOS and Linux. After the first load the simulator keeps working without an internet connection.
